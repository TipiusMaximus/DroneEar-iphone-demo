# DroneEar — iPhone Safari demo

This is a public iPhone Safari demo of DroneEar v0.1 DSP heuristic.

- Audio stays in the browser (nothing is uploaded or recorded).
- The on-screen score is **not** a probability.
- Open `index.html` via the jsDelivr HTTPS URL:

https://cdn.jsdelivr.net/gh/TipiusMaximus/DroneEar-iphone-demo@main/index.html
